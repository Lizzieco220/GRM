Values are each variable's 0 to 1 score before weighting. CPI is shown inverted, so higher means more corruption risk. Click a column header to sort. Sanctions and Crime are averages of their active sub-indicators.

Edit any raw value and the model recalculates. CPI is entered as the published score; the model inverts it (100 minus CPI) before normalizing. Min-max normalization uses the lowest and highest values among these 20 countries. US sanctions, Egmont, INCSR and FATF are already on a 0 to 1 scale and are used as entered, as in the spreadsheet.
